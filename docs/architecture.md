# Документация облачных сервисов

## Категории облачных решений

| Модель | Описание | Примеры |
| :--- | :--- | :--- |
| **IaaS** | Инфраструктура как сервис | AWS EC2, Yandex Compute Cloud |
| **PaaS** | Платформа как сервис | Heroku, Google App Engine |
| **SaaS** | Программное обеспечение как сервис | Google Workspace, Microsoft 365 |

## Назначение каталога
Документ содержит описание ключевых облачных моделей, архитектурных компонентов и требований к инфраструктуре.
